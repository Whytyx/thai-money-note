# โน้ตเงิน

แอปรายรับรายจ่ายแบบใช้ง่าย พิมพ์เป็นภาษาพูดได้เลย เช่น `ข้าวมันไก่ 50` หรือ `กาแฟ 2 แก้ว แก้วละ 45` แล้วระบบแยกชื่อ จำนวน ราคา และหมวดให้อัตโนมัติ

ใช้ได้บนมือถือและคอมพิวเตอร์ ทำงานออฟไลน์ได้ ข้อมูลเก็บในเครื่องคุณเท่านั้น (localStorage) ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มี API ภายนอก

## เปิดใช้

- เว็บ: https://whytyx.github.io/thai-money-note/
- ดูตัวอย่างข้อมูล (ไม่ถูกบันทึก): https://whytyx.github.io/thai-money-note/?demo

ติดตั้งเป็นแอปได้จากเบราว์เซอร์ (Add to Home Screen / ติดตั้งแอป)

## วิธีใช้

1. พิมพ์รายการในช่องว่าง หลายรายการคั่นด้วยจุลภาคหรือขึ้นบรรทัดใหม่ได้
2. ดูตัวอย่างที่แยกให้ แล้วกด **เพิ่มรายการ**
3. แตะหมวดเพื่อเปลี่ยน ครั้งถัดไปรายการชื่อเดียวกันจะจำหมวดนั้น
4. ดูยอดวันนี้ และสรุป 7 วันล่าสุด พร้อมคำแนะนำแบบกฎง่ายๆ จากข้อมูลของคุณเอง
5. ส่งออก CSV สำรองได้ หรือล้างข้อมูลในเครื่อง (มียืนยันก่อนลบ)

รายรับตรวจจากคำเช่น เงินเดือน, รายรับ, ได้เงิน, โบนัส, ขายได้ หรือขึ้นต้นด้วย `+`

## พัฒนาในเครื่อง

เปิดโฟลเดอร์นี้ด้วยเว็บเซิร์ฟเวอร์ธรรมดา แล้วรันเทสต์ตัวแยกข้อความ:

```
node tests/parser-test.js
```
